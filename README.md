# Wraith

The project was split into two repositories:

- **Android:** https://github.com/trinity13338/Wraith-android
- **Windows:** https://github.com/trinity13338/Wraith-windows

This repository only keeps copies of the latest releases. Wraith installations that still look for updates under the old name find them here, and after that update they check the new repositories.

> Русский: проект разделён на два репозитория — Wraith-android и Wraith-windows (ссылки выше). Здесь лежат только копии последних релизов. Старые установки найдут здесь обновление, а после него будут проверять обновления в новых репозиториях.
